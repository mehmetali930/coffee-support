# ☕ Coffee Support

A Web3 donation app where supporters can send small coffee-themed donations using **USDC on Arc Testnet**.

🌐 **Live App:** https://zesty-scone-616ca8.netlify.app

---

## What is this?

Coffee Support lets anyone connect their wallet and send a coffee donation (Full / Half / Quarter) to support a creator — fully onchain, no middleman.

- Choose from 5 coffee types: Americano, Caffè Latte, Cappuccino, Caramel Macchiato, Flat White
- Pick your size: Full (4 USDC), Half (2 USDC), Quarter (1 USDC)
- Confirm and send — all via your own wallet
- Donation history recorded onchain
- User profiles: name, bio, avatar

## Features

- Connect MetaMask, Coinbase Wallet, and other EVM wallets
- Auto network switch to Arc Testnet
- Onchain donation with USDC ERC-20 transfer
- User profiles stored onchain
- Admin dashboard (only visible to admin wallet)
- Mobile-first responsive design
